# VLM Evaluation Rubric

本文件用于对 VLM 在本项目 40 个图像问答样本上的输出进行人工评分。

## 评分标准

采用 **0–2 分制**：

| 分数 | 含义 | 判断标准 |
|---:|---|---|
| 2 | 正确 | 回答正确，且能够从图像中得到支持 |
| 1 | 部分正确 | 整体方向正确，但存在遗漏、轻微误读或细节错误 |
| 0 | 错误 | 答案错误、读错图像、答非所问或存在无依据的编造 |

评分时以 **最终答案是否正确** 为主，不因为表达流畅而额外加分。

## 评分重点

- **OCR**：关键文字是否识别正确
- **图表 / 表格**：数值、趋势、行列对应关系是否正确
- **架构图 / 论文图**：关键模块和结构关系是否理解正确
- **UI / 场景理解**：目标元素、物体、数量或空间关系是否识别正确
- **No-answer**：图中无法判断时，应明确表示无法确定，不能无依据猜测

## 错误记录

人工评分结果记录在：

```text
evaluation/manual_scores.csv
```

建议至少包含：

```text
image_id
question_id
model_name
model_answer
score
error_type
comment
```

其中 `comment` 用一句话说明评分原因即可。
